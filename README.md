# ErgoPulse

顔が近いときは「顔が近い」と文字でお知らせし、繰り返されるとねこが**「文字、小さくない？」**と表示拡大を提案。悪い姿勢が続くと、ねこが画面の半分ほどまで大きくなるデスクトップアプリです。さらに、通知後に姿勢を戻すまでの時間や「×」で閉じられた回数を記録し、飼い主に合う注意の仕方へ調整します。
Windowsでは `start_windows.bat` を起動するだけでカメラ判定・作業計測・別アプリ上の猫の表示を準備します。サイトの初期画面は設定パネルだけです。
作業メモは廃止しました。普段の画面はスクロール不要な設定パネルだけ。休憩タイマー・スマホ連携・デモ・比較検証用の履歴は「詳細機能・デモ・履歴を開く」から開けます。

## Windowsで起動する

1. ZIPを「すべて展開」します。
2. Python 3.11以上をインストール済みのPCで `start_windows.bat` をダブルクリックします。
3. 初回は依存ライブラリのインストールを待ちます（インターネット接続が必要です）。
4. ブラウザーで `http://localhost:8000` が開くと、カメラの使用を自動で要求します。**初回だけブラウザーで許可してください**。Windows側の小さな猫も自動で起動します。
5. 顔と両肩を映し、楽な姿勢で約3秒間の基準登録が終わったら、VS CodeやWordに移って使えます。
6. 終了は黒い画面で Ctrl+C を押します。ブラウザーを閉じるとカメラ判定は止まります。

以前の「`py` が見つかりません」エラーに対応し、起動ファイルは実在する `py -3` または `python` を自動で選びます。どちらもない場合はインストール方法を表示します。WindowsのCMDからインストールする場合は `winget install --id Python.Python.3.13 -e --source winget` を使い、完了後にCMDを開き直してください。

画面を見るだけなら `frontend/index.html` を直接開けます。
カメラ判定・スマホ同期を使う場合は付属サーバーを起動してください。

## ねこで姿勢変化を知らせ、原因を減らす（標準機能）

1. `http://localhost:8000` を開き、初回はカメラの許可を選びます。その後は許可済みのブラウザーなら自動開始を試みます。
2. 顔と両肩を映し、まっすぐな姿勢で3秒間基準登録します。実際には本人が楽に保てる自然な姿勢を基準にしてください。
3. 作業セッションも自動開始されるので、開始ボタンの操作は必要ありません。
4. スコア60未満の悪い姿勢が5秒を超えると、Windowsのねこが表示枠ごと徐々に拡大します。約30秒で、主画面の面積の約50%を使う表示枠が上限になります。ねこの絵はその枠に大きく描画します（透明部分もあるため、塗りつぶす画素面積が厳密に50%という意味ではありません）。70点以上に戻ると縮小します。
5. 標準6秒間スコア60未満が続くと、ページ内で小さなサインを表示します。75点以上を2秒保つと消えます。Windowsの一時停止を有効にしている場合は、次の条件で画面全体を覆います。

**VS Code・Word上の猫（Windowsのみ）**：`start_windows.bat` で通常は自動起動します。主画面の右下に通常約328×232pxの透明な小窓が現れます。巨大化を有効にすると、悪い姿勢の継続時間に応じて表示枠とねこを拡大します。60〜69点では成長を一時停止し、70点以上でリセットします。猫をドラッグすると配置を変えられ、「×」で2分間非表示にできます。猫が起動しなかった場合だけ `start_quiet_windows.bat` を追加で使えます（重複起動は抑止します）。猫を使いたくない場合は、サイトのチェックをオフにしてください。

**顔が近いときの表示と「文字、小さくない？」の拡大提案**：初回に登録した顔の横幅に対し、平滑化した見かけの横幅が1.25倍以上の状態が約1秒続くと、ブラウザーとWindowsのねこの上に **「顔が近い」** と表示します。1.15倍以下の状態が約0.75秒続くと解除します。肩が画面外へ出ても、顔を検出できていればこの警告は続きます。
さらに、**「顔が近い」が2回以上繰り返されると、ねこが「文字、小さくない？ 表示を大きくすると離れて作業しやすいよ」と提案**します（Windows側のねこにも「文字、小さくない？」と表示します）。「表示を大きくする（115% / 125%）」を選ぶと対応する画面の表示倍率を引き上げ、画面から離れて作業しやすくします。設定画面の「画面の表示倍率」からいつでも100% / 115% / 125%を切り替えられ、「設定・デモ操作」の「『顔が近い』繰り返し（文字拡大の提案）を試す」ボタンでカメラなしでも一連の流れを実演できます。

**飼い主に合う注意の仕方を覚えるねこ**：通知や巨大化の後に「姿勢が70点以上へ戻るまでの秒数」と、Windowsのねこの「×」やEsc・ブラウザーのスキップで「通知を閉じた回数」を記録します。小さなサインで素早く戻せる人や、巨大ねこを繰り返し閉じる人には通知開始を遅らせて控えめにし、巨大ねこが出てから姿勢を戻せる人には画面半分までの巨大化演出を優先します。

**巨大化の操作**：ねこの右上の「×」で2分間非表示にし、小さい状態から再開します。ドラッグで移動、右クリックで終了できます。ねこのウィンドウにフォーカスがある場合はEscでも非表示にできます。他アプリ使用中のEscをシステム全体で捕まえる処理はありません。動き・増殖をオフにしても巨大化は利用可能で、巨大化自体は専用のチェックでオフにできます。

**ねこの動き**：通常時は左右にお散歩・上下にゆれる・しっぽを振る・まばたきをします。姿勢の目安が70点以上になると、時々手を振ってハートを出したり、ゴロゴロ甘えたりします。60点未満ではそわそわし、低い姿勢スコアが5秒続くと子猫が1匹、13秒続くと2匹目が現れます。親猫と合わせて最大3匹です。70点以上に戻ると子猫は消えます。最初の画面の「ねこの動き・甘える・増殖を楽しむ」で一括オン／オフできます。オフでも姿勢に応じた親猫の大小変化は残ります。

**別モード：猫が2匹になったら全画面一時停止**：初期設定は巨大化がオン、全画面一時停止はオフです。最初の設定画面で「別モード：ねこ2匹で画面全体を覆う」をオンにすると、巨大化をオフにして切り替えます。60点未満が5秒続き、親猫と子猫で合計2匹になると、ほかのアプリの上にも姿勢を整えるための画面を表示します。**70点以上の姿勢に戻すと解除**します。`Esc` キーか「作業を再開する」で即解除して2分間は再表示しません。誤検知への安全策として**最長30秒で自動解除**し、カメラ計測が止まった場合も自動解除します。設定からいつでもオフにできます。

これは画面を覆って作業を一時中断する仕組みで、Windowsをロックしたり、システム全体のキー入力を無効にしたりする機能ではありません。`Alt+Tab` やWindowsのシステム操作で画面を切り替えられる場合があります。Windows版の実画面での表示確認は必要です。

最初の画面で変更できる設定：起動時カメラ自動開始のオン／オフ、浮かぶ猫のオン／オフ、ねこの動きと増殖のオン／オフ、巨大化と全画面一時停止の切り替え、飼い主に合う注意の仕方を覚える自動調整のオン／オフ、姿勢変化の通知までの秒数、休憩間隔、画面の表示倍率（100% / 115% / 125%）。カメラを止める・再試行する、姿勢の基準を再登録する、作業計測を一時停止する操作もここからできます。設定はこのブラウザーに保持します。

**自動開始の注意**：ブラウザーのセキュリティ機構により初回のカメラ許可は自動で通せません。拒否した場合やカメラが見つからない場合は、設定画面に状態を表示するので「カメラを開始・再試行」で再挑戦できます。

安全上の仕様：

- 子猫2匹以上の全画面一時停止はWindowsの小さなねこプログラムで行います。設定のチェックで停止でき、Escで2分間解除、30秒で自動解除します。従来の「研究用」停止は別機能で、ErgoPulseブラウザー内だけに作用します。
- 顔も姿勢も計測できない・計測が途絶える・休憩中・作業セッションの一時停止中は浮かぶ猫を隠します。姿勢だけ計測できず顔の近さを検出できる場合は、小さなねこと「顔が近い」の表示を残します。サーバーとの通信が3秒途切れてもWindows側の猫は自動で消えます。
- デモモードの姿勢スライダーで猫の成長を試せます。デモによる**Windows側のサインは出しません**。
- 浮かぶ猫は「×」で2分間休止、ドラッグで移動、右クリックで終了できます。ブラウザーがバックグラウンド処理を制限すると猫が消える場合があります。本体を終了すると自動起動した猫も終了します。
- **Windowsアカウントをロックしたり、他アプリのキーボード入力をシステム権限で無効化したりはしません**。浮かぶ猫は主画面の右下に、一時停止画面は可能な限り全モニターに表示します。
- 猫への状態連携APIはそのPCの `localhost` からしか使えません。スマホのQR連携ではWindows側の猫を操作できません。猫には姿勢スコアと顔の近さ・文字拡大ヒント・設定のフラグだけを渡し、カメラ画像・姿勢の座標は送信しません。
- スコア閾値は独自の目安です。実際の猫背や頸椎角を医学的に判定するものではなく、痛みが出るほど無理に姿勢を正す必要はありません。
- 猫の成長と静かなサインには上体の沈み込みと顔の接近だけを使用し、まばたきの減少のみでは変化しません。

手動起動：

```bat
py -m pip install -r backend/requirements.txt
py -m uvicorn main:app --app-dir backend --host 0.0.0.0 --port 8000
```

## VS Code・Word・別タブで作業するとき

1. ErgoPulseをブラウザーで開くと作業セッションも始まります。自動開始をオフにした場合だけ手動で開始します。
2. VS CodeやWordなど、普段のアプリへ移って作業します。時間は明示的に開始したセッションの経過時間として加算します。外部アプリのキーボード入力や画面内容は取得しません。
3. 手が止まった区切りでErgoPulseに戻り「いま一区切り」を押すと、姿勢・作業時間の条件に応じてスマホへ案内します。Gitコミット連携も使えます。別アプリの入力停止は自動判定しません。
4. 必要なら「通知の頻度・画面効果」からPC通知の使用許可を選びます。通知対応環境でページを開いていれば、別アプリで作業中に休憩間隔へ到達したときデスクトップ通知を表示します。通知は既定で無効です。
5. 「一時停止」「再開」「終了」を選べます。長時間（15分超）の処理間隔を検知した場合は、スリープ等の誤加算を避けるため自動停止します。

ブラウザーを閉じると計測は続きません。バックグラウンドのタイマーはブラウザーやOSによって遅れることがあります。これはWindows全体を監視する常駐アプリではありません。
外部作業中も姿勢の目安を得られるよう、ブラウザーでカメラの自動開始を試みます。必要なら上の設定で「カメラを停止」「再試行」ができます。ただしブラウザーによってはバックグラウンドでカメラ処理が停止・低速化されます。

## 高度な計測・比較検証と振り返り（任意）

1. 「詳細機能・デモ・履歴を開く」→「作業と休憩を振り返る」で「数値の記録を有効にする」をオンにします。
2. 今日の作業時間、姿勢変化率（計測できた時間のうち閾値に該当した割合）、動作完了回数、提案から動作完了まで進んだ割合に加え、**「姿勢を戻すまでの平均時間（秒）」「通知・ねこを閉じた回数」「顔接近回数（標準表示 ／ 拡大後）」「通知の邪魔さ自己評価（1〜5）」**と、過去7日間の作業時間を表示します。
3. 必要に応じて「履歴をCSVで保存」します。CSVには「巨大ねこ平均復帰秒数」「文字通知平均復帰秒数」「通知を閉じた回数」「顔接近回数（標準表示／拡大表示）」「邪魔度評価平均」も出力されるため、JPHACKSでの実演や通知方式の比較検証に利用できます。映像、顔・体の座標、入力したキーは保存しません。数値の記録をオフにすると集計履歴は削除されます。
4. さらに「自動調整」をオンにすると、延期・中止が続く場合は通知間隔を最大約2.5倍に伸ばし、姿勢復帰時間や閉じた回数に応じてねこの注意方法（控えめモード／巨大ねこ優先モード）を調整します。ユーザーの設定より頻繁には通知しません。調整内容は画面に表示します。

この自動調整は休憩や姿勢通知への反応に対する単純なルールであり、AIが疲労や生体状態を診断するものではありません。個人にとって効果的かどうかは未検証です。

カメラ判定は、短時間の姿勢スコアの変動を平滑化し、姿勢基準の登録時には顔の大きさ・肩と顔の相対位置の安定性を確認します。安定しない場合は3秒の登録をやり直します。処理時間に応じてフレームの取得間隔も調整するため、動作の滑らかさ・消費電力はPCによって変わります。

## まず90秒で実演する（カメラなし）

1. 「詳細機能・デモ・履歴を開く」→「設定・デモ操作」で「『顔が近い』繰り返し（文字拡大の提案）を試す」を押します。
2. 最初の設定パネルに「顔が近い」と、ねこからの**「文字、小さくない？ 表示を大きくすると離れて作業しやすいよ」**という提案が出ることを確認し、「表示を大きくする（115%）」を押して画面表示が大きくなる流れを実演します。
3. 続けて「設定・デモ操作」でデモモードをオンにし、姿勢スライダーを40にします。
4. 「作業セッションを開始」を押して、姿勢スライダーを左右に動かすと猫の大きさと子猫の出現が変わります。
5. スマホへ案内を送るデモも行う場合は「スマホ連携」でQRコードを読み取り、「いま一区切り」を押します。対応環境では音声と振動で知らせます。
6. スマホの「15秒の動きを始める」を押して、PCカメラの前で動くつもりで実演します。カメラなしでは15秒後、PCの「15秒動き終えた（手動確認）」を押します。

## 実際のカメラで検知する

1. デモモードをオフにし、PCは `http://localhost:8000` をChromeまたはEdgeで開きます。
2. 「設定・デモ操作」→「カメラ検知を開始」を押し、カメラの使用を許可します。
3. 顔と両肩を映し、楽な姿勢で3秒間待って基準を登録します。
4. 普段の姿勢から上体を下げたり、画面に近づいたりして変化を試します。
5. まばたきは最初の約1分を基準に、さらに約1分間観測して減少傾向を判定します。
6. 必要なら「今の姿勢を基準に登録し直す」を押します。

MediaPipe Pose / Face Landmarkerの推定をWeb Workerで実行します。
モデルと実行用ファイルを同梱しているため、カメラモデルの外部ダウンロードは不要です。
映像は送信しません。スマホへは数値の目安・介入モード・動きの進捗だけを送ります。

### カメラによる動きの完了判定

- バンザイ：両手首が肩より上にあることを15秒確認します。手首が見えない・腕を下ろす状態が1秒を超えるとやり直します（1秒以内は猶予）。
- 肩回し：肩回しそのものの3次元軌跡は測定せず、肩の上下動を3回以上、かつ開始から15秒以上で簡易判定します。
- 顔・肩は映っていても両手首が確認できないなど、選択した動きに必要な部位が判定不能なときは、15秒後にPC側で手動完了を選べます。
- 「中止」では完了回数を増やしません。

## スマホ接続で困ったとき

- PCとスマホを同じWi-Fiに接続し、スマホ側の画面を開いたままにします。
- QRコードはPC側で生成し、外部サービスには送りません。接続候補のアドレスが複数あるときは、QRの上の選択欄で別のアドレスに切り替えられます（社内VPNや仮想アダプターのIPが先頭になる場合）。
- localhostはスマホ自身を指すため、スマホではPCのIPv4アドレスのURLを使います。
- 自動表示されたIPで開けない場合、PCのコマンドプロンプトで `ipconfig` を実行し、接続中のWi-FiのIPv4アドレスをアプリに入力します。
- Windowsのファイアウォールに許可を求められた場合、使っているプライベートネットワークでPythonの通信を許可します。
- 大学やゲストWi-Fiの端末間通信が禁止されている場合、スマホのテザリング等、端末同士が通信できるネットワークを使います。
- iPhone/Safariなど振動非対応の環境では、画面と音声を使います。音声も端末の権限・日本語音声・消音設定などに依存します。「音声をもう一度聞く」も利用できます。
- バックグラウンド通知やロック画面での動作は保証しません。
- 接続URLは12時間で期限切れになります。再連携時は新しいURLをスマホで開いてください。
- 同じPCタブでページを再読み込みした場合は、期限内の接続情報を一時保存領域から復元して再接続を試みます。サーバー再起動や期限切れの場合は再連携が必要です。
- URLを知る端末が休憩の開始・延期・中止を操作できます。実演後はサーバーを停止します。
- 同梱サーバーはLANでの試作実演用です。インターネットへの公開設定は不要です。

## コミットや手動操作での区切り

詳細機能の「いま一区切り」から任意のタイミングで動きの案内を開始できます。
アプリ外の保存操作やキー入力は監視しません。
実際のGitコミットは、「スマホ連携」内のGit連携欄に表示するコマンドを対象リポジトリの `.git/hooks/post-commit` に自分で追記して連携できます（自動では書き換えません）。
ファイルが無い場合は先頭に `#!/bin/sh` を書き、`chmod +x` で実行権限を付けます。
キー付きフックは実演するPCのサーバーに送信し、その時点の姿勢・作業時間に応じて案内します。
連携し直すと接続キーが変わるためフックも更新してください。
「コミット完了を試す」でも同じ判定を実演できます。

## 姿勢状態と案内

- 姿勢が崩れると猫が大きくなり、60未満の姿勢目安が一定時間続くと小さなサインが出ます。Windowsの猫が2匹になるときは設定に応じて画面を最大30秒覆います。緊急時はEscで解除できます。
- 「顔が近い」が繰り返されたときは「文字、小さくない？」と表示拡大を提案します。
- コミットや手動の区切りでは、必要なときにスマホへ案内できます。外部アプリの入力停止は自動検知しません。
- 動きが完了した後は、1分間は再介入を抑えます。姿勢スコアを架空の改善値に書き換えません。
- 5分延期・中止にも対応しています。
- アニメーションを減らすOS設定に対応します。

## 通常の休憩・保存機能

短い休憩は20/25/30分間隔。20秒の目の休憩・30秒の姿勢変更・10分の作業休止を選べます。
作業セッションの積算が50分を超えると長めの作業休止を提案します。
短い休憩では長時間作業の積算はリセットせず、10分の休憩完了でリセットします。
設定と当日の休憩回数はこのブラウザーに保存します。以前の版で保存したメモは、新しい版では読み書きせず残しています。過去の文章は自動削除しません。
再読み込みで作業タイマーはリセットされます。

## 実装上の範囲

これは姿勢変化と作業の区切りを使う試作です。
- 正面カメラの肩・鼻の相対位置、顔の大きさの変化による目安です。首の実角度・距離cm・疲労・血流・ヒューマンエラー発生率は測定しません。
- まばたきは照明、眼鏡、撮影速度等に影響されます。検出できた回数の変化であり、医学的な疲労判定ではありません。
- Windowsの浮かぶ猫は付属の `start_windows.bat` で自動起動します。OS操作を禁止する機能ではありません。
- 作業セッションは起動時に自動開始し、別タブや別アプリの使用中も時間を加算しますが、キー入力や実際の集中度は監視しません。端末休止・バックグラウンド制限等で時間は不正確になる場合があります。
- コーチの言葉はルールに沿った日本語音声です。生成AIのクラウドAPIは使いません。
- 個人の姿勢改善、集中維持、疲労回復の効果は未検証です。
