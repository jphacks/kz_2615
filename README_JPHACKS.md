## 製品概要

### 背景（製品開発のきっかけ、課題等）

パソコンでのプログラミングやレポート作成に集中していると、顔が画面に近づいたり、背中が丸くなったりしても気づきにくい。姿勢に気を配り続けることは難しく、頻繁な通知は逆に作業の邪魔になる。

そこで、姿勢を管理するために別の画面を開くのではなく、**普段のデスクトップに住むねこを通して、自分の姿勢をさりげなく意識できる体験**を考えた。

### 製品説明（具体的な製品の説明）

ErgoPulseは、PCカメラとMediaPipeによる姿勢推定を使った、Windows向けのねこ型デスクトップ姿勢サポートアプリである。追加のマイコンやセンサーは必要ない。

起動後、顔と左右の肩が見える状態で約2秒間、ユーザー本人の楽な姿勢を基準として登録する。鼻と肩の相対位置や顔の見かけの大きさから、上半身の沈み込みや画面への接近を推定する。ブラウザーの右側ではライブカメラと認識状態を確認できる。

ねこはWordやVS Codeなどの**別アプリの上にも表示**される。姿勢が安定している間はお散歩・まばたき・しっぽ振り・ハートで甘える。悪い姿勢が継続すると、ねこが巨大化し、子ねこが最大2匹増える。**任意の全画面モードを有効にすると、姿勢スコア80未満を約3秒間継続したとき、一気に画面をねこで埋め尽くす。** 80点以上の姿勢を5秒維持すれば解除し、`Esc`・解除ボタン・30秒のタイムアウトでも安全に再開できる。

「ねこをリポップ」「ねこをなでる」ボタンには「にゃ〜」「ゴロゴロ」の合成効果音を用意。音量設定とミュートに対応し、ユーザーの操作がないときに勝手に鳴くことはない。

### 特長

#### 1. 姿勢に連動して表情・大きさ・数が変わるねこ

数字による注意だけでなく、ねこの巨大化・増殖・甘える仕草といったキャラクター表現で姿勢変化を伝える。通知を見るために作業を中断する必要がない。

#### 2. 任意の「3秒でねこまみれ」モード

悪い姿勢が連続約3秒検出されると、WordやVS Codeの上にねこが敷き詰められる。80点以上を5秒維持すると解除され、緊急時のEsc・解除ボタン・30秒自動解除・再通知抑制も備える。Windowsのシステム自体はロックしない。

#### 3. 専用デバイスなし・カメラ画像を外部へ送らない

PCカメラからブラウザー内でMediaPipe推定を実行し、Windowsに送るのは姿勢スコア等の数値情報のみ。個人の初期姿勢を基準にするため、絶対的な角度や距離を測定しなくても変化を可視化できる。

### 解決出来ること

- 集中によって姿勢が崩れても気づきにくい問題に、ねこの変化で気づくきっかけを与える。
- 姿勢確認のたびに別のサイトやアプリを開く負担を減らす。
- アラートだけでは無機質になりがちな姿勢管理を、愛着のあるキャラクターとの体験に変える。
- PCカメラを活用し、追加ハードウェアなしで利用を始められる。

**留意点**：スコアは画像から推定した姿勢変化の目安であり、猫背の医学的診断や効果の検証結果ではない。

### 今後の展望

- カメラ角度・座り位置の違いや検出信頼度を考慮した、より安定した姿勢推定
- 「寝る」「毛づくろい」「伸びをする」など、ねこの行動バリエーション
- 作業への邪魔になりにくさ、気づきやすさ、継続利用についてのユーザーテスト
- Windows向け実行ファイル化によるインストール負担の軽減

### 注力したこと（こだわり等）

- **作業を邪魔しにくい常駐UI**：通常は小さなねこだけを表示し、設定はブラウザーの1画面に集約。
- **一気に変化するねこ体験**：姿勢が一定時間崩れたら巨大化・増殖し、全画面を埋め尽くすユニークな演出。
- **安全に解除できること**：全画面表示は任意で、80点以上を5秒継続・Esc・解除ボタン・最長30秒で必ず解除する設計。
- **ふれあいとリラックス**：リポップ・なでる操作に対応する短い合成効果音とハート演出。音が不要ならミュート可能。

## 開発技術

### 活用した技術

#### API・データ

- MediaDevices API（`getUserMedia`）：カメラ映像の取得
- MediaPipe Pose / Face Landmarker：鼻・肩・顔のランドマーク推定
- Web Workers：UIと独立した姿勢推定処理
- WebSocket：任意のスマホ連携
- Local Storage：端末内の設定・任意の集計情報

#### フレームワーク・ライブラリ・モジュール

- JavaScript / HTML / CSS：ブラウザーUIとカメラ解析
- Python / FastAPI / Uvicorn：ローカルAPI
- Tkinter：Windowsのねこ・全画面ねこ表示
- Node.js / pytest：コードの自動テスト

#### デバイス

- Windows PC
- 内蔵またはUSB接続のWebカメラ
- スマートフォン（休憩案内機能を使う場合のみ・任意）

**今回マイコンは使用していない。**

### 独自技術

#### ハッカソンで開発した独自機能・技術

1. **基準姿勢と相対スコアの算出**：鼻・肩・顔の変化を測り、ノイズ平滑化と計測状態の確認を組み合わせる。  
   [`frontend/sensing.js`](frontend/sensing.js) / [`frontend/vision-worker.js`](frontend/vision-worker.js)
2. **常駐ねこのアニメーションと巨大化・増殖**：悪い姿勢が続く秒数に応じてねこの描画、数、サイズを変更する。  
   [`backend/desktop_guard.py`](backend/desktop_guard.py)
3. **全画面ねこまみれと安全な解除**：約3秒の継続判定、ねこの敷き詰め表示、Esc・30秒自動解除・カメラ不明時解除を実装。  
   [`backend/desktop_guard.py`](backend/desktop_guard.py) / [`tests/test_desktop_cat.py`](tests/test_desktop_cat.py)
4. **リポップ・なでる・鳴き声**：ローカルAPIを介して再表示やハートを操作し、合成効果音を再生する。  
   [`frontend/cat-audio.js`](frontend/cat-audio.js) / [`frontend/coach.js`](frontend/coach.js) / [`backend/main.py`](backend/main.py)
5. **起動と開発者向けテスト**：Windows起動用BAT、GitHub Actions、Python・JavaScriptのテストを整備。  
   [`ErgoPulse_START.bat`](ErgoPulse_START.bat) / [`.github/workflows/ci.yml`](.github/workflows/ci.yml)
