# ErgoPulse（エルゴパルス）― 巨大化するねこと「その人に合った助け方」で姿勢を支えるデスクトップ相棒

> **「顔が近い → 巨大ねこが気づかせる → 文字を大きくする提案 → 離れて作業できる → ねこが小さくなる」**
> ただ注意するだけでなく、前かがみの原因を減らし、使うほど飼い主に合う注意の仕方を覚えるデスクトップ姿勢サポートアプリ。

## 製品概要

### 背景（製品開発のきっかけ、課題等）

レポート作成やプログラミングなど、パソコンに集中していると、自分の姿勢の変化にはなかなか気づけない。気づいた頃には顔が画面に近づき、前かがみの姿勢を長時間続けていることがある。

一般的なリマインダーは一定時間で通知するが、通知を閉じるだけで元の姿勢に戻ってしまうことも多い。また、先行事例を調べると、カメラによる姿勢通知やキャラクター表示、画面ぼかしなど個別の要素には近い取り組みが存在する。

| 既存のサービス・作品 | ErgoPulseと重なる要素 | 既存アプローチだけでは残る課題・ErgoPulseの着眼点 |
| :--- | :--- | :--- |
| [Nekoze](https://apps.apple.com/jp/app/nekoze/id627505674?mt=12) | Macのカメラで姿勢を確認し、猫背になったら猫が通知する | 通知された瞬間だけ姿勢を直しても、作業に戻ると再び崩れやすい |
| [SitApp](https://sitapp.app/) | カメラ＋画面のキャラクターで姿勢を通知し、個人基準登録・音声・休憩案内・端末内処理を備える | 「なぜ顔が近づいているのか（文字が小さい等）」という作業環境側の原因までは減らせない |
| [Dorso](https://github.com/tldev/dorso) | 猫背になると画面が徐々にぼやけ、姿勢を戻すと解除する「画面への干渉」を行う | 強い干渉が一律にかかると、小さな通知で戻せる人には邪魔になり、逆に慣れると閉じられてしまう |
| [Axis](https://devpost.com/software/axis-qpk65z) ※ハッカソン作品 | 姿勢・まばたき等を検知し、ピクセル猫が反応・成長する | 作業中の気づきから「環境調整」「作業の区切りでの実動作リカバリー」までを一貫してつなぐ仕組みが必要 |

そこで私たちは、**「悪い姿勢が続くと画面の半分ほどまで巨大化するねこ」**という直感的な演出を軸にしながら、単に猫・育成・ローカル処理だけで終わらせず、**「その人に合った助け方」と「原因を減らす提案」**を加えることで独自性を高めた（※いずれも差別化のための設計であり、世界初を主張するものではない）。

1. **「顔が近い」の原因を減らすねこ**：「顔が近い」が繰り返されたら、ねこが**「文字、小さくない？」**と尋ね、ワンクリックで対応画面の表示倍率（115% / 125%）を上げて離れて作業しやすくする。その後、顔が近づく頻度が減ったかを記録して比較できる。
2. **飼い主に合う注意の仕方を覚えるねこ**：通知や巨大化の後に**「姿勢を戻すまでの時間」**や**「通知・ねこを閉じた回数」**を記録する。小さなサインで素早く戻せる人には控えめに（通知開始を遅らせ巨大化を抑える）、巨大ねこが効く人には画面半分までの拡大演出を使う。
3. **作業の区切り連動と、比較検証できる振り返り**：Gitコミットや「いま一区切り」のタイミングでスマートフォンへ15秒の動き（バンザイ・肩回し）を案内し、カメラで完了を判定する。さらに「普通の文字通知」と「巨大化するねこ」で**姿勢復帰時間・閉じた回数・邪魔に感じた度合い**を比較・CSV出力できる。

### 製品説明（具体的な製品の説明）

**ErgoPulse** は、パソコンのカメラと姿勢推定AIを利用した、ねこ型デスクトップ姿勢サポートアプリである。追加のセンサーやマイコンがなくても、PC（Webカメラ）だけで即座に動作する。

起動するとカメラによる計測を開始し、最初の約3秒間でユーザーの自然な姿勢を基準として登録する。その後、鼻・左右の肩の位置関係や、画面上の顔の大きさの変化から「上半身の沈み込み」「画面への接近」を推定し、姿勢の目安をスコア化する。

#### 1. 画面の半分ほどまで巨大化するデスクトップねこ（Windows最前面常駐）
ねこはWordやVS Codeなど、ほかのアプリで作業している間もデスクトップ上に表示される。姿勢が良いときにはお散歩やまばたき、しっぽ振り、ハートを出して甘えるなどの動作を見せる。一方、**姿勢スコア60点未満が約5秒を超えると、ねこが表示枠ごと少しずつ大きくなり、約30秒で主画面の半分ほどを使う大きさになる**（上限は主画面面積の約50%の表示枠）。60〜69点では拡大を止め、70点以上に戻ると小さくなる。60点未満が約5秒続くと子ねこが1匹、約13秒続くと2匹目が現れ、親ねこと合わせて最大3匹になる。

#### 2. 「顔が近い」の独立検知と、「文字、小さくない？」による表示拡大提案
登録した顔幅に対し、平滑化した見かけの横幅が1.25倍以上で約1秒続くと、ブラウザーとWindowsのねこの上に**「顔が近い」**と文字で表示する（1.15倍以下で約0.75秒続くと解除）。肩がカメラから外れても顔を検出できていれば案内を続ける。
さらに、**「顔が近い」が繰り返されたときには、ねこが「文字、小さくない？」と尋ね、「表示を大きくする（115% / 125%）」を選ぶと対応画面の表示倍率を引き上げる**。Windowsのねこの吹き出しにも「文字、小さくない？」を併記し、「顔が近い → 巨大ねこが気づかせる → 文字を大きくする提案 → 離れて作業できる → ねこが小さくなる」という一連の支援を行う。デモ用のワンクリック実演ボタンも備える。

#### 3. 飼い主に合う注意の仕方を覚える適応制御と、比較検証機能
任意の「作業と休憩を振り返る」を有効にすると、以下の指標を端末内に記録し、CSVで出力できる。
- **姿勢を戻すまでの平均時間（秒）**（巨大ねこモード／文字通知モード別にも集計）
- **通知・ねこを閉じた回数**（Windowsのねこの「×」やEsc、ブラウザーの一時スキップ回数）
- **顔接近の回数（標準表示時 ／ 表示拡大後）** と文字拡大の採用回数
- **通知が邪魔に感じた度合い（1〜5の5段階自己評価）**

「自動調整」をオンにすると、休憩の延期・中止が続く場合に再通知間隔を最大約2.5倍へ伸ばすだけでなく、**小さな通知で素早く姿勢を戻せる人（または巨大ねこを「×」で閉じる人）には通知開始を遅らせて控えめにし、巨大ねこが出てから姿勢が戻る人には画面半分までの巨大化演出を優先する**。

#### 4. 別モード（ねこ2匹で全画面一時停止）と、作業の区切りでのスマホ連携
設定で別モードへ切り替えた場合は、巨大化を止め、**ねこが合計2匹になった時点でWindowsの作業画面を一時的に覆う**（70点以上で自動解除、Escやボタンで即解除・2分間休止、最大30秒で自動解除）。また、手が止まった「いま一区切り」やGitコミット（`.git/hooks/post-commit`）のタイミングでスマートフォンへ音声・振動で案内し、PCカメラの前で15秒間の「バンザイ」「肩回し」の完了を判定できる。

### 特長

#### 1. 「顔が近い」の原因に踏み込み、作業を続けやすくする表示拡大提案
単に「顔が近い」と警告するだけでなく、繰り返された際にねこが**「文字、小さくない？」**と提案し、ワンクリックで画面の表示倍率（115% / 125%）を上げる。表示拡大の前後に「顔が近い」の頻度がどう変化したかも記録でき、姿勢が崩れる原因そのものを減らす。

#### 2. 画面半分まで巨大化するねこと、使うほど本人に馴染む注意方法の学習
「画面半分を埋める巨大ねこ」のインパクトを活かしつつ、通知後に姿勢を戻すまでの秒数と「×」で閉じられた回数を記録する。小さな通知で戻せる人には控えめに、巨大ねこが効く人にはその演出を使うルールにより、押しつけがましさを抑える。

#### 3. 普通の文字通知と定量比較できる評価ログ（復帰時間・閉じた回数・邪魔度）
ハッカソンでの実演やユーザー検証において、「普通の文字通知」と「巨大化するねこ」を切り替えて試し、**「姿勢を戻すまでの時間」「通知を閉じた回数」「邪魔に感じた度合い」「表示拡大前後の顔接近回数」**を画面とCSVで確認できるため、機能の効果を根拠付きで説明できる。

#### 4. 作業中のアプリの上で変化し、ユーザーがいつでも主導権を取り戻せる安全設計
ねこはWindowsの最前面に表示されるため、VS CodeやWordを開いたまま状態に気づける。巨大化しても右上の「×」で2分間非表示にでき、その後は小さい状態から再開する。カメラ画像はブラウザー内で解析し、外部へは一切送信しない。

### 解決出来ること

- **「顔が近い」と言われても文字が小さくて再び近づいてしまう問題**：ねこが「文字、小さくない？」と提案して表示倍率を上げ、離れたまま作業しやすくする。
- **一律の強い通知が邪魔になってオフにされる問題**：姿勢を戻すまでの時間や閉じられた回数から、その人に合った注意の強さ・間隔へ自動調整する。
- **集中していて姿勢の変化に気づかない問題**：ねこの段階的な巨大化（最大で主画面面積の約50%）や増殖を通して、別アプリで作業しながら状態を把握できる。
- **何が原因で通知されたのか分からない問題**：上半身の沈み込みと顔の接近を独立して判定し、「顔が近い」と具体的に知らせる。
- **追加機器の導入負担**：PC内蔵カメラとソフトウェアだけで導入できる。

※ 本製品は姿勢の変化を知らせ作業環境を整える試作であり、猫背の医学的診断や治療効果を保証するものではない。

### 今後の展望

- **PSOC Edge E84評価キットによる机上の「ねこのおうち」連携（構想・未実装）**：
  PSOCを使う発展案として、机の上に物理的な**「ねこのおうち」**を作る構想を検討している。
  1. **PCと机の上を同じねこが行き来する体験**：PC画面上で半分ほどまで大きくなったねこが、**飼い主が姿勢を70点以上に戻すと、スッと小さくなって机上デバイス（PSOC評価キット）の「ねこのおうち」へ帰って丸まって寝る**。
  2. **休憩案内と会議モードの逃がし先**：作業の区切りや休憩時には机側のねこが案内し、**オンライン会議や画面共有モードではPC画面上の巨大化を止め、机上デバイス側だけでこっそり「顔が近い」や姿勢変化を知らせる**。これにより、PC画面と机上デバイスを同じねこが行き来する体験と、物理デバイスならではの通知先としての役割を両立させる（現行ZIPに基板用ファームウェアは含まれない）。
- **外部エディター・OS全体の表示倍率連携**：現在はまずデモと検証がしやすいブラウザー内の表示倍率調整（100% / 115% / 125%）に対応しているが、将来はVS Codeの設定やOSの表示スケール連携へ広げる。
- **姿勢推定の高度化**：現行の鼻・肩・顔の見かけの大きさによる簡易推定を発展させ、頭部前方移動、肩の傾き、カメラ角度の影響を考慮する。
- **継続利用の比較検証**：収集できる「姿勢復帰時間」「通知を閉じた回数」「邪魔に感じた度合い」「拡大前後の顔接近頻度」を用い、複数ユーザーでのABテストを行う。

### 注力したこと（こだわり等）

* **「気づかせる」から「原因を減らす・本人に合わせる」への一歩**：「顔が近い → 巨大ねこが気づかせる → 文字を大きくする提案 → 離れて作業できる → ねこが小さくなる」という自然な流れを設計し、デモでもボタン1つで即座に再現できるようにした。
* **「注意する」より「気になる」設計と安全策**：姿勢の悪化をねこの巨大化や子ねこの増殖というユーモラスな出来事に置き換え、良い姿勢のときにはハートを出して甘える演出を用意した。最大サイズを主画面の約半分に制限し、「×」で2分間非表示にできる。
* **顔の近さの独立判定とヒステリシス**：肩が見切れた場合でも、顔を検出できれば「顔が近い」の案内を続ける。表示開始（1.25倍・約1秒）と解除（1.15倍・約0.75秒）で異なる閾値・継続時間を使い、境界付近で文字が点滅しにくくした。
* **根拠を示せる計測設計**：主観的な「良さそう」だけでなく、姿勢を戻すまでの秒数、通知を閉じた回数、表示拡大前後の顔接近回数、邪魔度の自己評価をローカルで集計・CSV出力できるようにした。

## 開発技術

### 活用した技術

#### API・データ

* **MediaPipe Pose Landmarker**：鼻・左右の肩・手首などの人体ランドマーク推定
* **MediaPipe Face Landmarker**：顔のランドマーク（顔幅の変化・まばたき）の推定
* **MediaDevices API（`getUserMedia`）**：PCカメラの映像取得
* **Web Workers / ImageBitmap**：姿勢推定処理をUIとは別のスレッドで実行
* **WebSocket**：オプションのスマートフォン連携
* **Web Speech API / Vibration API / Notifications API**：対応端末での任意の音声・振動・通知
* **Local Storage**：設定・表示倍率・振り返り指標（復帰時間・閉鎖回数・顔接近回数）を端末内に保存

#### フレームワーク・ライブラリ・モジュール

* **HTML / CSS / JavaScript**：1画面設定パネル・表示倍率制御・カメラ推定・適応ロジック
* **Python / FastAPI / Uvicorn**：ローカルサーバーと姿勢スコア・顔接近・文字拡大ヒント・閉鎖イベントの受け渡し
* **Tkinter**：Windows上に浮かぶ巨大化ねこと、作業一時停止画面の表示
* **MediaPipe Tasks Vision**：姿勢・顔の推定モデルのローカル実行

#### デバイス

* **Windows PC**（ノートPCまたはデスクトップPC）
* **PC内蔵カメラ、またはUSB接続Webカメラ**
* **スマートフォン**（休憩案内の連携時のみ・任意）

※ 現行の動作にはマイコンや追加の姿勢センサーは使用しない（PSOC Edge E84連携は今後の拡張構想）。
