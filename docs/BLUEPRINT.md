# ErgoPulse Coach：B×Cハイブリッド型 開発設計書＆Hack Day完全攻略ガイド

## 1. プロダクト概要とコアコンセプト

**プロダクト名（仮）**: **ErgoPulse Coach（エルゴパルス・コーチ）**  
**サブタイトル**: 集中を切らさず、画面の視覚変化とスマホの相棒介入で姿勢・疲労を整えるマンマシン協調AIエージェント

### なぜ「B（スマホ連携）× C（PC視覚ジャック）」の組み合わせが最強なのか

既存の姿勢改善アプリやタイマー通知が失敗する最大の理由は、**「集中している最中にポップアップや警告音で作業を邪魔するため、ユーザーが通知をオフにしてしまうこと」**にあります。

本プロダクトは、[マンマシンシステム](https://drive.google.com/file/d/1-x73W3hDRtyWzNQbKl-t6THES2CQ1Hcm/view?usp=drivesdk)のアプローチを取り入れ、作業者の集中状態（コンテキスト）に応じて**「アンビエントな視覚介入（C）」**と**「集中の切れ目を狙ったマルチデバイス介入（B）」**を2段階で使い分けます。

1. **集中している最中（パターンC：PC視覚ジャックによる無意識誘導）**  
   猫背・画面への顔接近・まばたき減少を検知しても、タイピングが続いている間は警告音を出しません。代わりに、**PC画面の周囲が徐々に曇る（または猫背の角度に合わせて画面がわずかに傾く・色温度が変化する）**ことで、集中を切らさずに「背筋を伸ばすと視界がクリアになる」という身体的なフィードバックを返します。
2. **集中の切れ目（パターンB：スマホ連携AIエージェントによる能動介入）**  
   疲労が蓄積した状態で「タイピングが3秒以上止まった瞬間」や「コミット・保存操作の直後」をAIエージェントが検知すると、手元のスマートフォンがWebSocket経由で即座に連動します。スマホが振動してAIコーチが立ち上がり、**「今のうちに15秒だけ肩を回そう！」と音声とアニメーションでガイド**し、PCカメラの前でバンザイや肩回しを完了するとPC画面の曇りが一気に晴れて爽快なクリア演出が走ります。

## 3. システムアーキテクチャと推奨技術スタック

2日間で確実に動き、かつデモ映えするレイテンシゼロの構成です。カメラ映像の骨格・顔認識はサーバーに送らず**ブラウザ内（MediaPipe Web）で処理**することで、通信遅延をゼロにします。

| レイヤー | 推奨技術スタック | 実装する具体機能 |
| :--- | :--- | :--- |
| **Sense（PC側センシング）** | `@mediapipe/tasks-vision` (Pose Landmarker + Face Landmarker) + JavaScript Keydown Event | ・両肩の中点と鼻・耳の座標から「頭部前傾（猫背）スコア」と「首の傾き角」を算出<br>・目のアスペクト比（EAR）から「まばたき頻度・眠気スコア」を算出<br>・打鍵間隔（Keystroke Interval）から「集中タイピング中」か「手が止まった切れ目」かをリアルタイム判定 |
| **Think（AIエージェント＆同期基盤）** | Python (FastAPI + WebSockets) または Node.js (Socket.IO) + LLM API (Gemini / OpenAI) | ・PCから送られる状態ベクトル（姿勢スコア・疲労蓄積時間・打鍵停止秒数）を監視<br>・Stage 1（アンビエント視覚介入）からStage 2（スマホ音声介入）への遷移を判断<br>・現在の作業時間や姿勢のクセに応じた「一言コーチング台詞」をLLMで動的生成（デモ用フォールバック定型文も用意） |
| **Act 1（PC側：視覚ジャックC）** | React / Next.js + Tailwind CSS + CSS Filter & Transform（またはElectron透過ウィンドウ） | ・猫背スコアに応じてワークスペース画面周囲にビネット（曇り・すりガラス効果 `backdrop-filter: blur()`）を段階的に適用<br>・首の傾きと逆方向（または同方向）にUIコンテナを数度傾ける視覚フィードバック<br>・リカバリー完了時の「ガラスが弾けて視界が100%クリアになる」エフェクト |
| **Act 2（スマホ側：相棒介入B）** | スマホブラウザ（PWA / レスポンシブWeb）+ Web Audio API / TTS + Vibration API | ・WebSocketで介入トリガーを受信した瞬間にバイブレーション＆警告ではなく親しみやすいAIボイスを再生<br>・スマホ画面上に「15秒ストレッチミッション（両手を上げてバンザイ／肩回し）」のリアルタイム達成ゲージを表示（PCカメラの骨格判定とリアルタイム連動） |

## 4. 優秀な2人チーム向け・ロール分担と2日間タイムスケジュール

2人が並行して開発を進め、**1日目（土曜日）の夜までに一通りの通信とエフェクトが繋がった状態**を作ります。

### ロール分担（疎結合で並列開発できる切り分け）

* **メンバー1（Sense ＆ PC視覚ジャック担当：フロントエンド・CV軸）**
  * MediaPipeを用いたWebカメラでの「猫背・顔接近・両手バンザイ（ストレッチ達成）」のリアルタイム検知ロジック実装
  * キーボード打鍵リズム（タイピング中／停止中）のステート管理
  * PC画面側の「曇り・傾き・色温度変化」および「クリア解放エフェクト」のUI実装
* **メンバー2（Think ＆ スマホ連携・AIエージェント担当：バックエンド・マルチデバイス軸）**
  * PCとスマホをミリ秒単位で繋ぐWebSocketサーバーの構築（QRコード1つでスマホがペアリングできる仕組み）
  * 「集中の切れ目×疲労度」から介入アクションを決定するAIエージェント＆音声合成（TTS）パイプラインの実装
  * スマホ側のAI相棒アニメーションUI・バイブレーション・リアルタイムストレッチ達成ゲージの実装

### Hack Day 2日間タイムスケジュール（チェックリスト）

- [ ] **Day 1 11:00 - 12:30｜インターフェース定義＆骨格構築**
  - GitHubリポジトリ作成、PC⇄サーバー⇄スマホ間でやり取りするWebSocketのJSONスキーマ（`posture_score`, `is_typing`, `intervention_stage`, `stretch_progress`）を5分で確定する。
- [ ] **Day 1 12:30 - 16:00｜コア機能（Sense & WebSocket疎通）の実装**
  - 【メンバー1】ブラウザ上でMediaPipeを動かし、猫背になった時にスコアが0〜100で変動し、バンザイしたら`stretch_done: true`になるデモ画面を作る。
  - 【メンバー2】WebSocketサーバーを立て、PC側のボタンを押したら手元のスマホ画面がリアルタイムに「通常モード→ストレッチコーチモード」に切り替わる通信を完成させる。
- [ ] **Day 1 16:00 - 20:00｜Act（PC視覚ジャック＆スマホAI音声介入）の結合**
  - 【メンバー1】猫背スコアに応じてPC画面がじわじわ曇る・傾くCSSエフェクトと、タイピング検知（手を止めて3秒でトリガー発火）を実装する。
  - 【メンバー2】トリガー発火時にLLM＋TTSで状況に合った音声（「30分集中してるね！今手が止まったから、10秒だけ一緒に背伸びしよう！」）をスマホから流す処理を繋ぐ。
- [ ] **Day 1 20:00 - 22:00｜通し結合テスト＆「デモ必勝モード」の仕込み**
  - PCで猫背になる→画面が曇る→手を止める→スマホが鳴る→バンザイする→PCとスマホが同時に「Recovery Complete!」になる一連のループを通しで動かす。
  - **重要ハック**: 会場の照明環境や通信状況が変わっても100%確実にデモが成功するよう、キーボードの隠しショートカット（またはスライダー）で閾値を即座に調整できる「デモ調整パネル」を入れておく。
- [ ] **Day 2 午前｜UIの磨き込み（ワクワク感の演出）＆GitHub整備**
  - 審査基準3「プロダクトにわくわくする（5点）」を取るため、スマホ側のAIキャラの表情変化や、姿勢が直った瞬間の爽快なサウンド・パーティクル演出を追加する。
  - オンライン審査（Award Day選出）で見られるGitHubのREADMEに、システム構成図とデモGIF/動画を載せる。
- [ ] **Day 2 午後｜録画・提出＆ライブデモ付きプレゼンリハーサル**
  - 1人目がスライド説明＋AIとの掛け合い、2人目が実機（PC＋スマホを審査員に見えるように掲げる、またはスマホ画面もプロジェクターにミラーリング表示する）で実演するロールプレイを3回通す。

## 5. 審査員の心を掴む「3分間プレゼン＆ライブデモ」構成案

1. **0:00 - 0:35｜共感を生む課題設定（着眼点）**
   * 「今この会場にいる全員に聞きます。昨日から今日にかけて、気づいたらこんな猫背でコードを書いて、目と肩がバキバキになっていませんか？ でも、集中している時に『姿勢を直してください』とポップアップが出たら、ウザくて消してしまいますよね。」
2. **0:35 - 1:15｜解決のアプローチ（着想点：Sense → Think → Act）**
   * 「だから私たちは、人間の集中を絶対に邪魔しないマンマシン協調AIエージェント『ErgoPulse Coach』を作りました。集中している間は画面の曇りや傾きだけで無意識に姿勢を誘導し、タイピングが止まった『集中の切れ目』だけをAIエージェントが狙い撃ちして、手元のスマホから物理的・視覚的にリカバリーを促します。」
3. **1:15 - 2:25｜ライブデモ実演（完成度・動作性の証明）**
   * **実演ステップ1**: ステージ上で実際に猫背になってタイピングする → プロジェクター上のPC画面の端がじわじわ曇り、画面が少し傾く（「タイピング中は通知を出さず、視覚変化だけで伝えます」）。
   * **実演ステップ2**: パッと手を止める → 2秒後に手元のスマホ（画面ミラーリング表示）が光り、AIエージェントが音声で「キリがいいね！肩が内側に入ってるから、10秒だけバンザイしよう！」と話しかける。
   * **実演ステップ3**: 発表者がカメラの前で大きくバンザイする → スマホのゲージが100%になり、PC画面の曇りが一気に弾けてクリアになる！
4. **2:25 - 3:00｜スケーラビリティと社会実装（実行可能性＆4社テーマ接続）**
   * 「特別なハードウェアは不要、今あるPCとスマホだけで今日から使えます。個人の開発や学習だけでなく、長時間の集中が求められる航空管制やインフラ監視の現場でヒューマンエラーを防ぐ安全技術としても展開可能です。」
