GitHubへのアップロード方法

1. このZIPを右クリックして「すべて展開」を選びます。
2. 展開後、README.md と backend、docs、frontend、tests が見える階層を開きます。
3. 更新先のGitHubリポジトリを開き、Add file → Upload files を選びます。
4. この階層のファイルとフォルダーをまとめてドラッグします。
   ZIPそのものや、これらを包む外側のフォルダーはアップロードしません。
5. アップロード内容を確認し、Commit changes で保存します。

README.md がGitHubの一番上に置かれると、その下に説明と画像が表示されます。
README_JPHACKS.md はJPHACKS提出向けの説明です。
.github などドットで始まる設定ファイルも含めてアップロードしてください。
一度に難しい場合は backend → frontend → docs → tests → 残りの順で分けて追加できます。

既存リポジトリの更新について
・同じパスのファイルは、このZIPの内容で更新されます。
・既存のLICENSEは削除しないでください。このZIPには新しいLICENSEを追加していません。
・GitHub上だけにあるファイルはアップロードでは削除されません。
・すでにGitHub上のREADMEを独自に編集している場合、このREADMEを送ると置き換わります。

起動方法
Windowsで ErgoPulse_START.bat をダブルクリックしてください。
Python 3.11以上が必要です。詳しくはREADME.mdを参照してください。
